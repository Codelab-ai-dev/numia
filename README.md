# Numia

Monorepo de Numia.

## Estructura

| Carpeta | Descripción |
|---------|-------------|
| `app/`  | App móvil Flutter |
| `api/`  | Backend en Go |
| `docs/` | Specs y planes de trabajo |

## Desarrollo

### App (Flutter)
```bash
cd app
flutter pub get
flutter run
```

### API (Go)
```bash
cd api
go run ./cmd/api
```
