# Monorepo Numia Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Unificar los repos `numia` (Flutter) y `numia-api` (Go) en un único monorepo reusando el repo `numia` como raíz, conservando la historia de git de ambos.

**Architecture:** El repo `numia` existente se mantiene como raíz. Todo su contenido Flutter se mueve a `app/`. El repo `numia-api` se incorpora bajo `api/` mediante `git subtree add`, lo que reescribe su historia bajo ese prefijo. El repo original `numia-api` queda intacto como backup.

**Tech Stack:** git (subtree), Flutter, Go.

**Spec de referencia:** `docs/superpowers/specs/2026-06-05-monorepo-design.md`

**Working directory:** `/Users/gustavo/Desktop/numia` (raíz del monorepo). `numia-api` está en `/Users/gustavo/Desktop/numia-api` (= `../numia-api`).

- [ ] **Step 2: Mover cada item de la raíz a `app/` (excepto `.git`, `docs`, `app`)**
